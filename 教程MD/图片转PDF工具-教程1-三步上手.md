## 导语

手机拍的纸直接交上去，常被挑出三个毛病：歪、有阴影、一张一个文件。扫描仪家里没有，在线转换站又要把发票和证件传上去。图片转PDF工具把「修成扫描件」和「合成 PDF」放在同一个本地流程里：右栏管整份 PDF（页面排版 + PDF 输出 + 成品预览），「编辑选中」窗口管单张图片，不用先回答「这是票据还是证件」。

## 开始之前

- 已安装并打开图片转PDF工具（支持 jpg / png / webp / bmp / tif / heic）
- 要转的拍照件、截图、扫描件放在能找到的位置，拖进来即可
- 断网也能跑完整个流程，原图一个字节都不会被改

## 操作步骤

### 1. 把图拖进左边

把图片或整个文件夹拖进窗口左侧，也可以点「选择图片」「选择文件夹」。左边立刻出现缩略图卡片，写着页序、文件名、原尺寸：按住卡片上下拖改页序（或用「上移 / 下移」），选中按 Delete 移出本批（只移出清单，不删原文件）。中文路径和手机竖拍的 EXIF 方向都能正确识别。

### 2. 右栏排页面

右栏「页面排版」是整份 PDF 的事：纸张（A4 / A5 / B5 / Letter / 自适应，默认 A4）、清晰度（72–600 dpi，默认 200）、边距（0–40 mm）、拼版（一页一张 / 上下两张 / 左右两张 / 2×2 四张）、页面方向（自动）与图间距。默认参数就能直接出可交的发票件。

### 3. 需要时勾页码、页脚与图注

「页码与页脚」默认关：勾上后可选位置、格式（1、1 / 5、第 1 页 / 共 5 页等）、起始页号与字号，页脚可写一行小字；页码落在边距里不压图，页码与页脚分列两侧互不遮挡。「图注与书签」里勾「图下方显示图注」可逐张填说明——IMG_2026… 这类纯编号文件名会被自动洗净，不会印一串数字在纸上；「生成 PDF 书签」默认开着，阅读器侧边栏一图一项，几乎不增体积。

### 4. 单张要修就点「编辑选中」

选中一张点左上「编辑选中」：窗口打开即显示这张图，一两秒内自动算出当前效果，参数一改（约 300 毫秒防抖）立即重算。修复项有裁边、纠偏、透视拉正、去阴影（关 / 轻 / 标准 / 强）、画面效果五档（彩色 / 彩色扫描件 / 增强扫描件 / 灰度 / 黑白 1 位无损）。裁边 / 纠偏 / 透视出厂默认全不勾——自动修复是基于估计的处理，要用的人自己点亮。勾「同时用于其它图片」则整批生效，不勾只改这一张。

### 5. 纸上要写字画框就点「页面编辑…」

点成品预览旁的「页面编辑…」开一个整页铺满的大窗口：图可拖动换位置、拖四角改大小（比例锁死），配「居中 / 铺满 / 复位本页」，PageUp / PageDown 翻页。工具条上有文字 / 方框 / 箭头 / 涂黑 / 签名图五类矢量标注：拖一下画出来，选中后可拖、可缩、按 Delete 删，文字双击改内容；点一下纸上已有的标注就是选中它，从框里直接拖就是移动。画错按 Ctrl+Z 撤销、Ctrl+Y 重做，最多 60 步。

### 6. 点「开始生成 PDF」

进度条走完，每张缩略图标「✓ 已处理 150dpi」，程序自动打开结果文件夹。PDF 默认在第一张图旁的 out 文件夹（右栏「PDF 输出」可另选目录），文件名带日期时间，同名自动加 (1)；每个 PDF 旁有同名 report.json，逐张记录实际 DPI 与处理链。

## 常见问题

### Q: 界面上怎么没有「票据报销」「证件材料」这类场景按钮？

A: v1.3 起刻意去掉了——那类一键按钮替用户做了决定，书、合同、试卷、画册都不适用。参数本身就是全部：纸张、清晰度、拼版在右栏改什么就生效什么，成品预览立即重排。

### Q: 拍的是书页、长图、网页截图怎么办？

A: 把纸张改成「自适应」，页面按图片自身比例成页，不会被压进 A4 变成中间一条；选自适应会自动锁成「一页一张」，建议同时关掉「透视拉正」，避免书页中缝被误判成纸边。

### Q: 原图会被修改吗？联网吗？

A: 不会、不联网。转换前算指纹、转换后复核大小，从不写回原图；「移出列表」也不删文件。核心代码静态扫描 0 处联网调用，运行期再挂 socket 计数，界面底部显示「本次 0 次联网」。

### Q: 中途取消会留下打不开的 PDF 吗？

A: 不会。PDF 先写 .part 再原子改名，取消不产出 PDF，进度与「✓ 已处理」痕迹一并复位；输出同名自动加 (1)，不覆盖上一批。

## 进阶技巧

- 发票、证件这类一两页的成品默认参数即可，去阴影以「编辑选中」画布上看到的为准。
- 褶皱纸、强反光、透字纸不保证救得回来，不满意就把对应开关关掉。
- 记住三处分工：右栏管整份 PDF，「编辑选中」管单张图片，「页面编辑…」管这一页怎么摆、纸上写什么。
